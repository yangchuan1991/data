# 获客系统项目

这是一个面向小型团队或个人创业者的获客系统原型，已扩展为更接近正式产品的版本，包含以下能力：

- 爬虫能力：可抓取目标网页内容并提取标题、摘要、链接，并记录爬虫任务
- 营销能力：支持创建营销活动、营销消息（邮件/短信）以及消息状态追踪
- 线索管理：可录入潜在客户信息并管理线索状态
- 数据分析与可视化：提供摘要指标、状态分布图表和操作日志
- 用户权限与角色：支持创建管理员、经理、观察者等角色用户

## 技术栈

- Python 3.11+
- SQLite
- 标准库 HTTP Server
- 可扩展到 Scrapy 的爬虫架构

## 项目结构

- app.py: 数据层、爬虫解析逻辑、分析与权限逻辑
- server.py: 本地 Web 服务与页面渲染
- tests/test_app.py: 单元测试
- requirements.txt: 依赖说明

## 快速开始

1. 创建虚拟环境
   - python3 -m venv .venv
   - source .venv/bin/activate

2. 运行应用
   - python3 server.py

3. 浏览器访问
   - http://127.0.0.1:8000/

## 当前已实现功能

- 图表分析：线索状态、渠道分布、营销消息状态的可视化条形图
- 真实爬虫框架适配：当前通过标准库抓取，并保留对 Scrapy 的兼容入口
- 邮件/短信营销：支持创建营销消息并记录发送目标人数与状态
- 用户权限与角色：支持创建不同角色用户并记录到数据库

## 后续可扩展方向

- 接入真实 Scrapy 爬虫任务队列
- 增加报表导出、邮件自动化、短信接口对接
